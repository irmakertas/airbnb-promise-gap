# Airbnb Promise Gap

Data Mining and Business Intelligence Course Project

## Project Overview
This project aims to investigate the gap between Airbnb listing promises and actual guest experiences using data mining and business intelligence techniques.

## Project Structure
- data/ : Datasets used in the project
- notebooks/ : Jupyter notebooks for data analysis
- reports/ : Analysis results, visualizations, and reports

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook
- Matplotlib
- Seaborn
